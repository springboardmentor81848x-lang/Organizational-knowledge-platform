# KGap Intel - Organizational Knowledge Platform
KGap Intel is a modern Android application designed to serve as a centralized hub for organizational knowledge sharing and collaboration. It features a sleek, user-friendly interface built with Material Design 3 and a robust architecture.

## Features
*   **Premium Authentication**: Secure Login and Registration system with real-time password validation.
*   **Splash Screen**: Professional animated entry screen with custom branding.
*   **Knowledge Hub**: Centralized repository for documents, guides, and internal wiki.
*   **Role-based Access**: Managed user roles (Admin/Member) via JWT authentication.
*   **Modern UI**: Built using Material Design components, CardViews, and custom emerald-themed gradients.

## Tech Stack
*   **Language**: Java
*   **Architecture**: MVVM (Model-View-ViewModel)
*   **Networking**: Retrofit 2 & OkHttp
*   **UI Components**: Jetpack (LiveData, ViewModel, ViewBinding)
*   **Design**: Material Design 3 (M3)
*   **Local Storage**: SharedPreferences for session management
